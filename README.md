## 📖 Overview

This **Library Management System** is a lightweight, responsive web application designed to help librarians and administrators manage their book collections with ease. It features a modern **Admin Dashboard** that provides at-a-glance metrics of library activity.

### 🌟 Key Features

*   **📊 Dynamic Dashboard:** Visual summary of library statistics.
*   **📖 Book Cataloging:** Add, edit, and delete book entries in real-time.
*   **🔍 Advanced Search:** Filter books by title, author, or ISBN.
*   **📱 Fully Responsive:** Works seamlessly on mobile, tablet, and desktop screens.
*   **⚡ Fast Performance:** Hosted on Netlify for high-speed delivery.
